# earkiller6002-s-csv-filter

Для создания ".env"-файла нужно открыть файл ".env.example" и ввести следующие данные, например такие:
"INPUT_FILE=data/users.csv
OUTPUT_FILE=data/result.csv
MIN_AGE=18
CITY_FILTER=Moscow"
После этого сохраняем файл ".env.example" и переименовываем его в ".env"

Для запуска в cmd или в bash нужно ввести команду "npm start")
